# Subsection screenshots

Actual community-supplied screenshots are pending. Until supplied, the reader uses intentional navy placeholders marked Screenshot pending, with persistent live-text labels. Region overview tiles do not claim to be named subsections.

In Studio → Subsections & screenshots, edit the name and confirmed region, choose a PNG/JPEG/WebP file, add meaningful alt text and credit, and set focal X/Y between 0 and 1. Order is editable with up/down. Subsection associations let one entry appear in several places without cloning the record; confirming a subsection's region makes its associated discoveries accessible in that region.

Budget: up to 2 MB per image, maximum 4096px in either dimension; about 1600px wide is recommended. Use permissioned assets only. SVG uploads are rejected. The reader crops to 16:9 with object-fit and the normalized focal point; it does not stretch imagery.

Upload creates only a local draft preview. Export includes the actual image bytes at its final `public/images/subsections/` path and the alt/credit/focal metadata. Commit both before expecting a public image. Do not claim an unpublished upload is a hosted asset. No generated imitation game screenshots are used.

Screenshot paths are immutable. Uploading a replacement creates a fresh path and changes the content revision; the Studio cannot overwrite bytes at a published path. Credits are visible on the public screenshot tile.
